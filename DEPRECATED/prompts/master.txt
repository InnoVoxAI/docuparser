## 7. BACKEND - CHAT_CONSUMER.PY (WebSocket Handler)

O nosso chat será esse Multiagente abaixo com todas as capacidade
Agentes (LangGraph StateGraph)
🕵️ Supervisor - Analisa intenção
📚 Bibliotecário - Busca contexto semântico (FAISS)
💻 Eng. SQL - Gera query DuckDB
⚖️ Auditor - Valida SQL (segurança)
🚀 Executor - Executa e retorna dados
Features Técnicas
✅ DuckDB in-memory (Parquet local)
✅ LangGraph (State Machine rígida)
✅ RAG Semântico (FAISS para mapear termos)
✅ Validação hardcoded (Python, não LLM)
✅ Streaming de trace (cada agente reporta)
✅ Self-correction loop (SQL inválido volta ao Eng. SQL)

- Receber mensagens via WebSocket
